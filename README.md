# ImmerLex

Иммерсивный словарь юридической терминологии Казахстана на казахском, русском и английском языках.
Проект Жетысуского университета им. И. Жансугурова.

**Открыть:** https://kaxmtv-art.github.io/ImmerLex/

## Что внутри
- Трёхъязычный словарь юридических терминов
- 3D-сцены и сценарии дел
- Гостест: подготовка к тестированию на госслужбу (eQyzmet): корпус «А», корпус «Б», правоохранительная служба, госязык, тренажёр ОЛК
- Коммерциализация: тарифы, курсы повышения квалификации, сертификат, AI-проверка документов, API, версия для вузов, калькулятор дохода, дорожная карта

AI-функции, заявки и проверка сертификатов работают в версии на claude.ai; на GitHub Pages остальные разделы работают офлайн.
